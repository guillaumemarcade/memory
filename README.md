# English Memory Game

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Memory card game to learn English vocabulary, built with plain JavaScript.

## How to play

- Flip cards to find matching pairs
- Each pair shows an English word and its image
- Match all pairs to win

## Getting started

```bash
git clone https://github.com/guillaumemarcade/mes-mots.git
cd mes-mots
# Open index.html in your browser
```
